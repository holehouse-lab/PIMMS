# PIMMS Colab notebooks

Interactive notebooks that run PIMMS in a free Google Colab session — no local install
required.

### Phase separation demo

Install PIMMS from PyPI, run a small lattice simulation of "sticky" polymers that phase
separate into a dense droplet, and view the trajectory in an interactive 3D viewer.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/holehouse-lab/PIMMS/blob/master/colab/pimms_phase_separation_demo.ipynb)

> The "Open in Colab" badge opens the notebook directly in Colab once this repository is
> on GitHub (`holehouse-lab/PIMMS`, `master` branch). Runtime is about a minute end to
> end, most of it compiling PIMMS' Cython kernels on first install.
